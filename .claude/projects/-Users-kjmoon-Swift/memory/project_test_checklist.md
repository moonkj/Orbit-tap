## 실기기 테스트 체크리스트

시뮬레이터 테스트 완료 (10/10 크래시 없음, URL scheme 5/5). 아래는 실기기에서만 검증 가능한 항목.

### 플로팅 버튼
- [ ] 1탭 → 뒤로가기
- [ ] 2탭 → 앞으로가기
- [ ] 3탭 → 제스처 모드 (파란 테두리)
- [ ] 꾹 2초 → 가이드 오버레이
- [ ] 꾹 0.4초 + 드래그 → 위치 이동
- [ ] 페이지 전환 후 위치 유지 (날아오기 없음)
- [ ] BFCache (뒤로/앞으로) 후 버튼 동작

### 제스처 (제스처 모드에서)
- [ ] X 두 획 → 탭 닫기 + 토스트
- [ ] L → 새 탭 + 토스트
- [ ] ○ 원 → 검색바 + 토스트
- [ ] C → 새로고침 + 토스트
- [ ] 인식 실패 → "다시 시도" 토스트
- [ ] 5초 무입력 → 자동 해제

### 팝업 설정
- [ ] 마스터 토글 ON/OFF → 저장 유지
- [ ] 각 제스처 토글 → ON/OFF 저장 유지 (탭 닫고 다시 열어도)
- [ ] 크기 S/M/L → 버튼 크기 변경
- [ ] 투명도 슬라이더 → 버튼 투명도 변경
- [ ] OFF 제스처 → 제스처 모드에서 동작 안 함
- [ ] 플로팅 버튼 OFF → 화면에서 사라짐
- [ ] 플로팅 버튼 ON → 새로고침 없이 나타남

### 구독
- [ ] 10회 사용 후 → 구독 프롬프트
- [ ] "구독하기" → 앱 구독 화면 이동 (PaywallScreen)
- [ ] 구독 화면에 구독 버튼 있음
- [ ] 관리자 5탭 → 비밀번호 → Pro 토글
- [ ] Pro 전환 → 무제한 사용
- [ ] Pro 전환 → 팝업에 "Pro 무제한" 표시
- [ ] 통계 초기화 동작

### 다국어
- [ ] 한국어 기기 → 전체 한국어
- [ ] 영어 기기 → 전체 영어
